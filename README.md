# SciQ RAG: Document Quality and Context Intervention Analysis

This repository contains my final active project files for a local, reproducible RAG study on the [SciQ](https://huggingface.co/datasets/sciq) multiple-choice QA benchmark.

The central question of the project is:

> How does document quality affect LLM(RAG) performance?

To answer that, the project compares:

- a normal retrieved-document setting,
- targeted context interventions that remove or compress evidence,
- a distractor-noise condition,
- and an oracle gold-support condition that serves as an upper bound.

The repository also includes final paper figures, a compact qualitative case-study artifact, and my individual paper PDF.

## Main Findings

Using the committed aggregate results in this repository:

- `LLM-only`: `0.4373`
- `RAG baseline (baseline_k3_full_context)`: `0.8093`
- `Oracle gold support`: `0.8727`
- `Remove answer sentence`: `0.4823`
- `Only answer sentence`: `0.8187`
- `Add distractor context`: `0.7660`
- `Shuffle context order`: `0.8187`

The most important pattern is the expected document-quality ordering:

`oracle gold support > normal retrieved document > corrupted document`

Numerically:

- `oracle_gold_support = 0.8727`
- `baseline_k3_full_context = 0.8093`
- `A_remove_answer_sentence = 0.4823`

This shows that better evidence quality raises performance, while removing answer-bearing evidence causes a large drop.

## Models and Setup

The committed scripts use:

- dataset: `SciQ`
- generator: `google/flan-t5-small`
- retriever encoder: `sentence-transformers/all-MiniLM-L6-v2`
- vector index: `faiss`
- evaluation size: validation `n = 1000`
- seeds: `0, 1, 2`

This project uses local models and local evaluation scripts rather than external LLM APIs.
